**Install** · Download **Pickverter-*.dmg**, open it and drag Pickverter into Applications.
It is signed and notarized by Apple, so it opens like any other app. After that Pickverter updates itself from this page.

**설치** · **Pickverter-*.dmg**를 내려받아 열고 Pickverter를 응용 프로그램 폴더로 끌어 놓으세요.
Apple 공증을 받은 앱이라 다른 앱처럼 바로 열려요. 그 다음부터는 이 페이지의 새 릴리스로 자동 업데이트됩니다.

`Pickverter-*.zip` and `update.json` are used by the built-in updater · `SHA256SUMS.txt` lists checksums.
