**Install on Windows** · Download **Pickverter-*-win-x64-setup.exe** (or **win-arm64** for Snapdragon PCs) and run it — no administrator rights needed.
The installer isn't code-signed yet, so SmartScreen may say "Windows protected your PC": click **More info › Run anyway**.
Pickverter then waits in the notification area and updates itself from this page.

**Windows 설치** · **Pickverter-*-win-x64-setup.exe**(스냅드래곤 PC는 **win-arm64**)를 내려받아 실행하세요. 관리자 권한은 필요 없어요.
아직 코드 서명이 없어 "Windows의 PC 보호" 창이 뜨면 **추가 정보 › 실행**을 눌러 주세요.
그 다음부터 Pickverter는 알림 영역에 머물며 이 페이지의 새 릴리스로 자동 업데이트돼요.

`Pickverter-*-win-*.zip` (portable) and `update-windows.json` are used by the built-in updater · `SHA256SUMS-windows.txt` lists checksums.
